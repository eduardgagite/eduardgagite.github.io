Пишу на Go, но этот проект — на Swift. Трекер личных финансов для iPhone: транзакции и категории, долги с погашениями, графики на Swift Charts, бэкапы с авто-ротацией, блокировка по Face ID, виджет на экране «Домой» и премиум-подписка через StoreKit 2. Есть локализация на русский и английский. Внешних зависимостей нет вообще, только системные фреймворки — так меньше чужого кода, за которым надо следить.

Самое интересное тут не интерфейс, а то, как бэкендные привычки переехали в мобильную разработку. Деньги хранятся как Int64 в минорных единицах, вся арифметика идёт через один модуль с saturating-операциями на границах диапазона. Double в денежной логике не встречается нигде — так же, как в банковском бэкенде.

С конкурентностью похожая история. Тяжёлая аналитика считается вне главного потока: сервисы статистики изолированы акторами, между контекстами данные ходят только в виде Sendable-снапшотов. По сути то же разделение, что горутины, каналы и `-race` в Go, просто на другом языке.

Отдельно возился с устойчивостью к порче данных. Повреждённое хранилище не роняет приложение — файл уходит в карантин, а пользователь видит экран восстановления из бэкапа. Перед импортом с заменой автоматически снимается бэкап, при открытии стора записи дедуплицируются по UUID. На телефоне у человека нет админа, который починит базу, поэтому приложение должно выкручиваться само.

Тесты писал с первого дня: регрессионные на денежную логику и бэкапы, плюс перформанс-бенчмарки. В CI на GitHub Actions гоняются сборка и тесты на симуляторе, а отдельный скрипт сверяет ключи локализации между ru и en — без него расхождения всплывали бы уже у пользователей.

Версия 1.0 готова, проект потихоньку развиваю дальше. Для Go-разработчика это странный пункт в портфолио, но тем он и полезен: привычки вроде тестов с первого дня и целочисленных денег пережили смену языка без потерь.
