Самый крупный мой проект и по совместительству полигон — мессенджер в духе Signal и старого ВК. Личные и групповые чаты со сквозным шифрованием, стена, лента, звонки. Делаю его один и каждую подсистему собираю так, как собирал бы в рабочей команде.

Бэкенд — один сервис на Go со слоями server → service → storage. HTTP-API на Fiber, realtime через WebSocket-хаб, PostgreSQL с pgx, MinIO под медиа, web-push для уведомлений. Сервер по задумке не видит переписку: тексты и файлы шифруются на клиентах, у него остаются только шифртексты и обмен публичными ключами.

Сообщение нельзя терять между базой и сокетом, поэтому доставка построена на transactional outbox. Событие пишется в таблицу outbox той же транзакцией, что и сами данные, LISTEN/NOTIFY будит поллер, событие уходит клиенту, тот отвечает ack. Всё неподтверждённое переотправляется после реконнекта, так что схема переживает и разрыв соединения, и рестарт сервера, и падение в любой точке между записью и отправкой.

Авторизация держится на ротации refresh-токенов. Каждый refresh одноразовый, а попытка использовать уже потраченный трактуется как компрометация — все сессии пользователя отзываются. Сами токены и SMS-коды хранятся в базе только как SHA-256. Регистрация по номеру телефона с подтверждением кодом, вход по username или телефону, обычные JWT access + refresh.

Модель ключей сделана по мотивам Signal: identity key, подписанный prekey и пачка одноразовых prekeys, сервер выдаёт key bundle собеседника и следит, чтобы пачка не кончалась. Звонки один на один идут через WebRTC, бэкенду достаётся только сигналинг по WebSocket, медиа течёт peer-to-peer под DTLS-SRTP. Тут есть незакрытый кусок: серверная часть E2E готова целиком, а шифрование на клиенте пока частично в заглушках.

Отправка сообщений идемпотентна по client-id — повтор запроса после таймаута не создаёт дубль. Историю листаю keyset-пагинацией, без OFFSET. Статусы доставки и прочтения живут в отдельной подсистеме receipts.

Интеграционные тесты гоняю на testcontainers-go, каждый прогон поднимает настоящий PostgreSQL в контейнере — мокать базу не хотелось. В CI на GitHub Actions крутятся gofmt, go mod verify, govulncheck, сборка и тесты. Плюс метрики Prometheus с дашбордами в Grafana, структурные логи slog с request-id и graceful shutdown.

Веб-клиент тоже мой: React с TypeScript на Vite, TanStack Query и Zustand, собственный WebSocket-менеджер с переподключением, офлайн-кеш в IndexedDB, PWA, структура по FSD, юнит-тесты на Vitest. Живёт в Docker за nginx, наружу выходит через Cloudflare Tunnel.

Главный компромисс — сервис пока single-instance. Outbox-поллер и WebSocket-хаб не разъедутся на несколько машин без внешней шины вроде Redis Pub/Sub или Kafka, и это осознанный трейд-офф: добавлю шину, когда в неё упрусь.
